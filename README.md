# DSCI 552 homework

Coursework for DSCI 552, Machine Learning for Data Science, USC, Fall 2026.

Each homework has its own folder. A notebook reads its data with a relative path
from the folder it sits in, so it runs after cloning with no changes.

## Running

    pip install -r hw2/requirements.txt
    jupyter notebook hw2/Zhang_Zhengshu_HW2.ipynb
